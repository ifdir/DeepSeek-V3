MATRIX10 - Arbeitsstand 10a - Android (aarch64)
================================================

STATUS: ROT - KEINE Produktfreigabe. ANDROID: GEBAUT, AUF ANDROID UNGETESTET (kein Geraet verfuegbar).

WICHTIG - DIE HAEUFIGSTE URSACHE FUER "503 Rust-Schreibgrenze konnte nicht geladen werden":
  * Das LINUX-Paket (x86_64) auf dem Handy benutzt -> nur das Paket "android-aarch64" verwenden.
  * Das Paket liegt in Download / sdcard / "Interner Speicher". Von dort darf Android KEINE Bibliothek laden.
    -> Paket ins Termux-Home entpacken (Schritt 1 unten).
Neu in 10a: START.py prueft den Rust-Kern beim Start und schreibt den Grund hin. Die Oberflaeche zeigt oben einen roten
Balken mit Grund und Abhilfe, solange der Kern nicht geladen ist. Beruehrungs-Eingaben werden bis dahin NICHT gespeichert.

Voraussetzungen
---------------
- Android-Handy mit 64-Bit-ARM, Termux (aus F-Droid), Android 7 oder neuer
- In Termux:   pkg install python unzip
               pip install flask
  (Pydroid 3: dort liegt das Paket meist im Speicher "Download" -> Bibliothek nicht ladbar. Bitte Termux verwenden.)

Starten
-------
1. Im Termux-Home entpacken (NICHT in Download/sdcard starten):
     termux-setup-storage            (einmalig, erlaubt Zugriff auf Download)
     mkdir -p ~/m10 && cd ~/m10 && unzip ~/storage/downloads/MATRIX10_STAND10A_PRODUKT_android-aarch64_<commit>.zip
2. cd MATRIX10_STAND10A_PRODUKT_android-aarch64_<commit>
3. python START.py
   Es muss erscheinen:  [RUST] Einwilligungskern geladen (ABI 3, Geraet aarch64).
   Steht dort [RUST-FEHLER] ..., nennt die Zeile den Grund und die Abhilfe.
4. Browser: http://127.0.0.1:8080   (API: http://127.0.0.1:5050). START.py versucht ihn selbst zu oeffnen.

Falls der Kern trotz Termux-Home nicht laedt ("Lader meldet: ... cannot locate symbol ..." o. ae.):
     bash RUST_AUF_DEM_HANDY_BAUEN.sh
   (installiert bei Bedarf Rust in Termux, baut den Kern auf dem Handy, prueft ihn; danach python START.py)
   Bitte die [RUST-FEHLER]-Zeile zurueckmelden, falls auch das scheitert.

Ohne Modell-Schluessel aendern Erlebnisse Gefuehl, Absicht und Beziehung NICHT. Mit Schluessel: Provider + API-Key unter
"Konfiguration" eintragen (nie in den Chat). Echtes Modell in diesem Stand NICHT abgenommen (BLOCKIERT).
Offene Punkte: MATRIX10_STAND10A_STATUS.json und MATRIX10_STAND10A_START.txt.
