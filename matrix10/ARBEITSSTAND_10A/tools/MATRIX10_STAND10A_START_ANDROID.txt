Was 10a fuer dein Handy repariert:
- Der Fehler "503 Rust-Schreibgrenze konnte nicht geladen werden" bei Beruehrungs-Eingaben kam daher, dass Android aus
  Download / Interner Speicher keine Bibliothek laden darf (Pydroid 3 + Ordner in Download). P25 brauchte keine.

  Der Ordner darf in Download bleiben. Nachgestellt und geprueft auf einem solchen Speicher (Pruefprotokoll 9d).
- Beim Start steht: [RUST] Einwilligungskern geladen (...). Laedt er trotzdem nicht, steht dort der Grund, und in der
  Oberflaeche erscheint oben ein roter Balken mit Grund und Abhilfe.

Wichtig: das ANDROID-Paket verwenden (Name enthaelt "android-aarch64"), nicht das Linux-Paket.

Pydroid 3
---------
1. ZIP entpacken (z. B. in Download), wie bisher.
2. In Pydroid 3: Menue -> Pip -> "flask" installieren (einmalig).
3. START.py im entpackten Ordner in Pydroid oeffnen und ausfuehren (gelber Knopf).
4. In der Ausgabe muss stehen: [RUST] Einwilligungskern geladen
5. Browser: http://127.0.0.1:8080 (START.py versucht ihn selbst zu oeffnen).

Termux (Alternative)
--------------------
   pkg install python unzip && pip install flask

   mkdir -p ~/m10 && cd ~/m10 && unzip ~/storage/downloads/MATRIX10_STAND10A_PRODUKT_android-aarch64_<commit>.zip
