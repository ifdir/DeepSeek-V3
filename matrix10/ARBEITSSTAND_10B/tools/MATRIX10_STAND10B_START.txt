Voraussetzungen
---------------
- Linux x86_64, Python 3.11 oder neuer (geprueft mit 3.13)
- Python-Paket Flask:   python3 -m pip install -r requirements.txt
  (Node/npm und Rust werden zum START NICHT gebraucht - Frontend und Rust-Bibliothek sind fertig gebaut.)

Starten
-------
1. ZIP in einen NEUEN, leeren Ordner entpacken.
2. cd MATRIX10_STAND10B_PRODUKT_linux-x86_64_<commit>
3. python3 START.py   (die Zeile "[RUST] Einwilligungskern geladen" muss erscheinen; sonst steht dort der Grund)
4. Browser selbst oeffnen: http://127.0.0.1:8080   (API: http://127.0.0.1:5050)
   (Unter Linux oeffnet START.py den Browser nicht automatisch.)
   Andere Ports, falls 8080/5050 belegt: MATRIX_UI_PORT=8180 MATRIX_API_PORT=5150 python3 START.py
Datenbank: data/matrix10.sqlite (wird beim ersten Start mit der eingebauten Welt angelegt).

Ohne Modell-Schluessel: unter "Konfiguration" Provider "Nur lokale Synapse (kein LLM)" waehlen. Dann antworten die
Figuren mit der lokalen Synapse (kein KI-Text). Mit Schluessel: Provider + API-Key unter "Konfiguration" eintragen.
WICHTIG: Ohne Schluessel veraendert ein Erlebnis (z. B. ein Schlag) Gefuehl, Absicht und Beziehung einer Figur NICHT -
die Bedeutung liefert das Modell, der Server prueft und speichert sie (mit Testmodell gemessen: F1 erfuellt).
Die Verwendung eines echten Modells ist in diesem Stand NICHT abgenommen (BLOCKIERT).
